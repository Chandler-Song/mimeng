# 其实，99%的自闭症小朋友都上会画画

实习生：左容容


其实，99%的自闭症小朋友都不会画画
原创
 2017-08-29 咪蒙 咪蒙
今天被“小朋友画廊”刷屏了。
据说，其中很多绘画者，是自闭症人士。
大家看了，都在惊呼，哇，这些自闭症人士好厉害啊，好有天赋！简直都是天才


啊！
可能大家下意识地觉得，我们承认了自闭症人士是天才，把他们称为“星星的孩
子”，很诗意，很人文，很有关怀。
但是，恕我直言，这种看法对自闭症孩子以及他们的家长来说，没有任何卵用。
特教老师李老西今天也说了，很多自闭症家长听到“自闭症都有天才的部分，特别
是有作画数学的天分”这种话的时候，真的有句MMP不知当讲不当讲。
因为公众认识中的自闭症，那么牛逼，那么屌窜，和他们在真实生活中所接触、所
认知的自闭症，完全不是一回事。
公众想象中的自闭症，有点浪漫，有点美好，那是《雨人》、那是《地球上的星
星》，他们都是动不动就逆袭的天才……
而真实生活中，99%的自闭症人士都不具备所谓的天分。
他们往往生活都不能自理。
他们可能随地大小便。
他们可能没法表达自己的需求。
就像李老西所说的：我反对所有将自闭症儿童的一切浪漫化理解的行为。他们不是
来自外星的孩子，他们和我们一样都是地球人而且是弱化版的。
作家蔡春猪，他有一个8岁的自闭症孩子，他说，当你认为自闭症患者都是天才，
那对大多数不是天才的自闭症患者来说，是不公平的。
之前看蔡春猪的书《爸爸爱喜禾》，有个情节印象深刻。
喜禾妈妈带他去海洋公园，喜禾第一次认识鱼了，他指着鱼喊，“鱼”，就单纯这
一件事，对他们整个家庭来说，就是标志性的大事。
喜禾妈妈告诉蔡春猪的时候，他在电话那头，眼泪都掉下来了。
事后他一直很激动地缠着老婆问各种细节，比如喜禾当时是用哪个手指，指着鱼
的…… 
我想说的是，自闭症绝对不是什么浪漫的病，更不是很多人所认为的简单的“性格
孤僻、不爱说话”……
我采访的所有密集接触自闭症人士的人，都认同一点：
如果你在生活中遇到一个自闭症患者，千万别以为他只会在你身边，安安静静地画
画。更可能发生的是，他刚见面，就会冲过来摸你的头发…… 
只有当我们知道自闭症有多么不浪漫之后，还愿意接纳他们，理解他们，这才是最
理性的事。
更可怕的是，还有些人把自闭症等同于天才，就跑去对自闭症孩子的家长，说一些
伤人的话。
采访中，一个家长就说，总有人问她，你女儿会画画吗？


如果她回答说，不会。
对方脸上就有一丝惊讶、以及一丝责备。
接着对方就会给她一些“善意的提醒”，比如，为什么你不找人教她学画画呢？不
是说自闭症都是天才吗，你们是不是没有好好挖掘啊？她实在没法告诉对方，自己
的女儿，现在6岁，智商才21。
她试过让女儿画画，给了她纸和笔，示范了怎么画画。
然后女儿把纸撕得稀巴烂，把笔拿进嘴里吃……
撕纸、把任何东西都放进嘴里吃，这才是大部分自闭症孩子的真实反应。
对他们来说，画画这种精细动作，太高端了。
还有一些家长，也被“自闭=天才”的理论所误导，尤其是那些刚刚确诊孩子患了
自闭症的家长，他们也许会把重心放在发现和培养孩子所谓的特长上，不仅给孩子
带来负担，还耽误了对孩子自身障碍进行及时的科学干预——而这才是一个自闭症
孩子被诊断后，家长最需要做的事。
也许你会问，我们不能把自闭症等同于天才，也不能随便给他们贴标签、下定义，
那我们该怎么对待自闭症？
首先，如果在公众场合遇到他们，请不要说他们是熊孩子。
一个在自闭症康复机构工作了5年多的老师说，当你在地铁上、餐厅里等公众场
合，发现有奇怪的孩子高声大叫、或者乱扔饭菜的时候，先不要认为对方是一个没
教养的“熊孩子”，他有可能是一个在陌生环境感到焦虑，但不知道该如何正确表
达的自闭症孩子。
他讲了一个例子。
他曾经和一个十几岁的自闭症孩子，以及她的妈妈，一起去吃饭。
当时，因为餐厅没有她点的菜，她就情绪爆发——因为根据她的刻板思维，她会认
为，既然菜单上写了有这道菜，就应该有……
她当时一直追着店员问，为什么，为什么，为什么…… 
当时这位老师在现场，一瞬间就完全代入了自闭症家长的心情，感到难堪、尴尬和
无助，而且很希望能得到别人的理解，但是周围的人只是瞪着他们，眼神里都是反
感和责备。
孩子妈妈只能拼命地跟店员和顾客解释，不好意思孩子有自闭症，她不是故意这样
的……
那个妈妈说，“有了一个这样的孩子，我几乎就永远失去了在公众场合保持体面生
活的资格。”
其次，如果他是你孩子的同学，请不要把他赶出去。
同事的儿子5岁，他们班有一个自闭症孩子。


幼儿园园长再三跟家长们保证，那个孩子只是反应迟钝一点，他绝对没有暴力倾
向，不会伤害任何人。
即使如此，家长们还是联名写信，要求自闭症孩子退学。
甚至有个奶奶情绪激动地怒斥园长，说，凭什么我交了这么多钱，我的孙女要和弱
智在一起上课？
自闭症孩子在学校里被排挤、被欺负是常态。
作为家长，我们可不可以教孩子去理解、去体谅、去帮助这个同学，而不是欺负
他。
再次，遇到自闭症孩子的家长，不要乱问问题。
我采访的大部分自闭症孩子的家长都很烦，总是被问一些特别没有礼貌的问题，而
且他们已经了回答了100遍，还要再回答101遍。
关键是，那些人完全不了解自闭症，还自以为很有爱心，做各种“专业指导”，比
如，“你多陪孩子玩，他很快就会好的。”“肯定是因为出去少了，你带他出去多
见见人，他就不会自闭了……”
坦白说，有一个自闭症孩子已经非常痛苦了，还要应付这些傻逼问题，他们真的很
心累。
如果我们不是专业人士，什么都做不了，至少可以做到有距离的尊重。
采访当中，自闭症孩子的家长都说，这么多年了，媒体都没有进步，提到自闭症，
还是“天才”、“星星的孩子”那一套，这并不是他们真正需要的。
他们真正需要解决的，是现实问题。
第一，孩子去哪看病？我们的自闭症服务体系相较美国差了大概六七十年左右，在
美国一个孩子被诊断后，能立马获得好的干预资源，而我们现状是干预机构鱼龙混
杂，甚至频繁会出现孩子在骗子机构受到错误训练，被殴打，甚至被虐待致死的悲
剧。
第二，孩子去哪上学？自闭症孩子到了入学年龄，没有学可以上。
第三，孩子长大了怎么办？到了青春期怎么办？该工作了怎么办？我们缺乏对自闭
症人士的就业支持体系，他们很难找到工作。
第四，父母老了以后，孩子怎么办？这是每一个自闭症家长，最难面对的问题。采
访中，一个很难过的发现是，几乎每个自闭症孩子的家长，都想过带着孩子一起去
死。
今天，我们给自闭症蒙上了一层美好的外衣——天才、好看的画作。这种苦难中的
美好难能可贵，于是我们在朋友圈疯转。
但我还是想说，大部分的他们不会画画，不是天才，甚至有点烦人，只有苦难没有
